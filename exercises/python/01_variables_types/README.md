# Exercício 01: Variáveis e Conversão de Tipos

## Objetivo
Praticar atribuição de variáveis, operações matemáticas e conversão explícita de tipos (de `str` para `float`).

## Requisitos
1. `calcular_retangulo(largura, altura)`:
   - Área = largura * altura
   - Perímetro = 2 * (largura + altura)
   - Retornar como tupla `(area, perimetro)`
2. `converter_temperatura(celsius_str)`:
   - Recebe string como `"25.5"`
   - Converte para float, aplica fórmula `(C * 9/5) + 32`
   - Retorna arredondado com `round(..., 1)`
