# Nível 11: Coleções Avançadas (Set e Map)

## Objetivo
Utilizar `Set` para unicidade O(1) e `Map` para associações chave-valor sem as limitações de objetos simples.

## Requisitos
1. `intersecao<T>(a: T[], b: T[])`: Retorna elementos presentes em ambos os arrays sem duplicatas usando Set.
2. `criarDicionarioPrecos(itens: [string, number][])`: Cria e popula uma instância de Map. Adiciona método para buscar preço com fallback.
