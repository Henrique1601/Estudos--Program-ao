# Nível 09: Métodos de Array Funcionais (Map e Filter)

## Objetivo
Manipular coleções sem laços imperativos e sem efeitos colaterais.

## Requisitos
1. `obterNomesAprovados(estudantes, notaCorte)`: Filtra estudantes com nota >= notaCorte e retorna apenas os nomes em maiúsculas.
2. `removerFalsy<T>(itens)`: Retorna um novo array contendo apenas os elementos truthy.
