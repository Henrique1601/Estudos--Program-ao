# Nível 03: Laços e Acumuladores

## Objetivo
Praticar controle de fluxo com laços (`for`, `while`) e simular mentalmente a mutação de estado.

## Requisitos
1. `somarPares(numeros: number[])`: Retorna a soma de todos os números pares do array.
2. `contarVogais(texto: string)`: Retorna o total de vogais (a, e, i, o, u - maiúsculas ou minúsculas, desconsidere acentos).
3. `fatorial(n: number)`: Retorna o fatorial de n. Lança RangeError se n < 0.
