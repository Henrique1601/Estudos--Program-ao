# Nível 10: Agregações com Array.prototype.reduce

## Objetivo
Compreender a mecânica do acumulador em transformações complexas de dados.

## Requisitos
1. `contarFrequencia(palavras: string[])`: Retorna um objeto `{ [palavra]: quantidade }`.
2. `agruparPor<T, K>(itens, seletor)`: Agrupa itens em um objeto onde cada chave aponta para um array.
