# Nível 07: TypeScript - Interfaces e Modelagem

## Objetivo
Estruturar dados de negócios com interfaces fortes e tipos imutáveis.

## Requisitos
1. Modelar interface `ItemVenda` com `{ id: string, nome: string, precoUnitario: number, quantidade: number }`.
2. Modelar interface `Recibo` com `{ totalBruto: number, desconto: number, totalLiquido: number }`.
3. Implementar `gerarRecibo(itens: ItemVenda[], percentualDesconto: number): Recibo`.
