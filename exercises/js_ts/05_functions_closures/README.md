# Nível 05: Funções, Escopo e Closures

## Objetivo
Entender como variáveis continuam encapsuladas na memória via closures e construir funções de ordem superior.

## Requisitos
1. `criarContador(inicial = 0)`: Retorna `{ incrementar(): number, obter(): number, resetar(): void }`.
2. `memoizar<T, R>(fn: (arg: T) => R)`: Retorna uma função que armazena em cache chamadas anteriores com o mesmo argumento.
