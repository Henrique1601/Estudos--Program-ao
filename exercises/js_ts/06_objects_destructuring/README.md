# Nível 06: Objetos e Desestruturação

## Objetivo
Manipular dicionários e registros em JavaScript com spread e desestruturação.

## Requisitos
1. `selecionarPropriedades<T, K>(obj, chaves)`: Retorna um novo objeto contendo apenas as chaves especificadas (Pick).
2. `mesclarConfiguracoes<T, U>(padrao, sobrescrita)`: Faz merge superficial garantindo que propriedades sobrescritas substituam as padrões.
