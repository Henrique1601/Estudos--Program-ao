# 🥋 Cérebro do Projeto Code Sensei

Bem-vindo ao seu **Segundo Cérebro de Aprendizado Deliberado**. Este cofre contém os mapas conceituais, metodologias pedagógicas e arquiteturas necessárias para você dominar programação e desenvolvimento de software sem atalhos ou ilusão de fluência de IA.

> [!important] Objetivo Central
> Construir modelos mentais sólidos ("Notional Machine") e memória muscular através de prática deliberada, testes imediatos e reflexão ativa.

## ⚡ Comandos de Ação Rápida no Terminal

| Comando | O que faz | Quando usar |
| :--- | :--- | :--- |
| `python main.py` | Menu interativo completo | Ponto de partida |
| `python main.py watch` | Monitoramento em tempo real + Auto-commit | Ao codificar no editor |
| `python main.py duck` | Sessão com o Pato Socrático | Travou em um erro |
| `python main.py trace` | Blind Trace (compilador mental) | Treinar previsão de código |
| `python main.py hint [ex] [1..3]` | Dica progressiva socrática | Precisa de luz sem ver código |
| `python main.py boss` | Bateria de Boss Fights | Testar arquitetura |
| `python main.py log` | Registrar aprendizado | Após resolver bug difícil |
| `python main.py stats` | Relatório de progresso | Acompanhar evolução |
